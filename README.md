# Информационная система автосервиса

Учебное веб-приложение для автоматизации работы небольшого автосервиса: клиент подаёт заявку и следит за её статусом, мастер ведёт назначенные работы, администратор управляет мастерами, услугами и заявками.

## Возможности

- Роли клиента, мастера и администратора
- Регистрация и вход с хранением хешей паролей
- Заявки на обслуживание и история смены статусов
- Подбор мастера по навыкам и текущей загрузке
- Каталог услуг, автомобили клиентов, уведомления и статистика
- Реляционная схема данных и миграции Alembic
- Диаграмма сущностей в `er_autoservice.drawio`

## Технологии

Python 3.12, Flask, Flask-SQLAlchemy, SQLAlchemy, Flask-Login, Flask-WTF, Alembic, SQLite, Bootstrap 5, Jinja2.

## Локальный запуск

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Приложение читает настройки из переменных окружения. Задай их в текущей оболочке (или настрой загрузчик `.env` самостоятельно), затем примени миграции и запусти приложение:

```bash
export SECRET_KEY="replace-with-a-random-secret"
export DATABASE_URL="sqlite:///autoservice.db"
export AUTOSERVICE_DEMO_PASSWORD="choose-a-local-demo-password"
flask --app run.py db upgrade
python run.py
```

Для наполнения локальной базы демонстрационными данными задай `AUTOSERVICE_DEMO_PASSWORD` и запусти:

```bash
python seed.py
```

База данных, виртуальное окружение, локальные переменные и кэш интерпретатора не входят в репозиторий.
